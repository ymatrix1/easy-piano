# Git workflow

- `main` is current state. Branches: `feat/`, `fix/`, `docs/`, `research/`, `chore/`, one concern each. Planning-phase doc edits may go to `main`.
- Conventional Commits (`feat(core): …`, `docs(spec): …`), subject ≤ 72 chars, body explains why.
- Verify locally before committing.
- PR description: Context, Higher Goal, Acceptance Criteria, Out of Scope, Summary of Changes, bean IDs, roadmap phase.
- Never commit `references/`, build outputs, caches, large binaries, or reference-app material.
- GitHub account is `ymatrix1`.
