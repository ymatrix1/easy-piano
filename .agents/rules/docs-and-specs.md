# Docs and specs

- `docs/PRD.md` scope, `docs/ROADMAP.md` phases, `docs/specs/<topic>.md` design, `docs/DECISIONS.md` decisions, `docs/OPEN-QUESTIONS.md` unknowns, `docs/research/` findings.
- Behaviour, interface or decision change → update the spec in the same PR.
- Every decision: **Context, Decision, Why, Alternatives, Impact**, **Status** (`proposed`/`accepted`/`superseded`/`rejected`), **Decided by** once decided. Agents write `proposed`; only the user accepts. Accepted decisions are frozen; changes supersede.
- Answered open question → remove it, record the answer in a decision or spec.
- Research files start with: Checked date, sources, Question; end with Implications and Follow-ups.
- Write directly: tables, short sentences, no filler.
