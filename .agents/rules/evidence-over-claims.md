# Evidence over claims

- Don't say a change works until a test or check that exercises it ran **after** your last edit and passed. Show the command and relevant output.
- If you couldn't run a check, say so and why.
- Latency and fps claims need a measurement on a named device with the same setup before and after.
- Pitch-detection accuracy claims need the fixture set and the score (precision/recall/F1).
