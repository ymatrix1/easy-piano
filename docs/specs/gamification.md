# Gamification

Status: draft.

| Mechanic | Rule |
|---|---|
| Stars | 0–3 per level/song ([exercise engine](exercise-engine.md)) |
| Star gates | Journey node needs N stars from listed songs |
| Boss levels | End-of-course review; unlock next course |
| Daily goal | Minutes practiced (default 10), user-set |
| Streak | Days meeting daily goal; 1 freeze earned per 7 days |
| Daily workout | 5-min mix from weakest recent levels |
| Feedback | Instant key colors, combo counter, end-of-level recap with best moments |
| Badges | Course complete, 3-star songs, 7/30/100-day streaks |

Rules: no dark patterns, no loss-aversion notifications, notifications opt-in. Kids mode: simpler visuals, no streak pressure.
