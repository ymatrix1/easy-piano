# Internationalisation (i18n)

Status: implemented for en, pt-BR, es, fr, de ([D16](../DECISIONS.md)). Bean: `piano-exsg`.

## Two string tables

| Text | Where | Format | Fallback |
|---|---|---|---|
| App UI (menus, buttons, tooltips, result messages, banners) | `app/lib/l10n/app_<locale>.arb` | ARB, Flutter `gen-l10n` (`app/l10n.yaml`), typed getters on `AppLocalizations` | Missing key = build error; the test keeps every ARB complete |
| Lesson content (course, node, level titles, descriptions, scene captions) | `content/strings/<tag>.json` | Flat `key → text`, referenced as `str:key` in content files | Active tag → base language (`de` for `de-AT`) → `en` → the key itself |

Rule of thumb: text in Dart code is an ARB key; text in a `content/` file is a `str:` key. Content authors never touch ARB files; app developers never put UI text in `content/strings`.

Not translated: the developer spike pages (MIDI latency, staff render) and debug output.

## Languages

| Tag | UI ARB | Content file | Picker name |
|---|---|---|---|
| `en` | `app_en.arb` (template, has `@key` descriptions) | `en.json` (source of truth) | English |
| `pt-BR` | `app_pt.arb` + `app_pt_BR.arb` (empty, inherits `pt`; gen-l10n needs the base language) | `pt-BR.json` | Português (Brasil) |
| `es` | `app_es.arb` | `es.json` | Español |
| `fr` | `app_fr.arb` | `fr.json` | Français |
| `de` | `app_de.arb` | `de.json` | Deutsch |

The list lives in `AppLanguage.all` (`app/lib/l10n/app_locale.dart`). Translations are machine-assisted and reviewed for music terms; native-speaker review is welcome via PR.

### Adding a language

1. `app/lib/l10n/app_<locale>.arb` with every key of `app_en.arb`.
2. `content/strings/<tag>.json` (may start partial; lint warns).
3. Add an `AppLanguage` entry (tag, `Locale`, endonym).
4. Decide note naming (below) and set `middleCLabel`.
5. `flutter test` (key parity), `cargo run -- lint ../../content`.

## Choosing the language

- Default: first device locale with an exact tag match, else the same language (`pt-PT` → `pt-BR`, `es-MX` → `es`), else English. Device locale changes are followed while no explicit choice is stored.
- Profile → Settings → Language: "Device default" or one of the languages, shown by endonym.
- The choice is stored per device with `shared_preferences` (key `language`; web: `localStorage`). "Device default" removes the key.
- Switching is live: `MaterialApp.locale` changes, `ContentRepo.locale` is set, and every element is rebuilt so content strings re-resolve. Navigation and progress state are kept.

## Note naming

A design choice per locale, used in UI strings and content strings alike.

| Locale | System | Middle C | Example | Notes |
|---|---|---|---|---|
| en | Letters | C | C, D, E, F, G, A, B | |
| de | Letters, German | C | C, D, E, F, G, A, **H**; B = B♭ | Write `H` for B natural in content. Sharps/flats: Cis, Es (when used in prose). |
| pt-BR | Fixed-do solfège | Dó | Dó, Ré, Mi, Fá, Sol, Lá, Si | Capitalised, with accents. |
| es | Fixed-do solfège | Do | Do, Re, Mi, Fa, Sol, La, Si | Capitalised, no accents. |
| fr | Fixed-do solfège | do | do, ré, mi, fa, sol, la, si | Lower case in running text; capital at start of a title. `Do` on the keyboard label. |

- The on-screen keyboard's middle-C landmark uses the ARB key `middleCLabel` (`C`, `Dó`, `Do`, `Do`, `C`).
- Staff notation is universal; note names are never drawn on the staff.
- Octave numbers (C4) stay scientific pitch notation in every locale and appear only in developer views.
- Song titles in `songs/*.json` are not translated (proper names); level/node titles that name a song may be (e.g. "Hymne à la joie").

## Checks

| Check | Fails on | Where |
|---|---|---|
| `flutter test test/l10n_test.dart` | ARB missing or stale key vs `app_en.arb`; an `AppLanguage` without UI locale or content file; fallback order; live switch | app |
| gen-l10n (part of `flutter build/test`) | ARB syntax, placeholder mismatch | app |
| `content lint` | `str:` key missing in `en.json` (error); non-text value in a locale file (error) | tools/content-cli |
| `content lint` | Key in `en.json` missing in a locale (**warning**, English fallback); key not in `en.json` (warning, stale) | tools/content-cli |

Content gaps only warn so new lessons can land in English first and be translated later.

## Out of scope

RTL languages, translated song files, voice-over (OQ6), per-locale number formatting beyond what `intl` gives.
