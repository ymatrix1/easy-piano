# Glossary

| Term | Meaning |
|---|---|
| Course | Named unit (Piano Basics 1) with a journey |
| Journey | Graph of nodes inside a course |
| Node | Lesson, song, star gate, boss or workout on the map |
| Level | Ordered list of stages; the thing you start and finish |
| Stage | One exercise: wait, play_along, one_note, animation, quiz |
| Wait mode | Song time stops until correct note is played |
| Play-along | Timed stage driven by the audio clock |
| Critical section | Bar range whose hit ratio decides pass/fail |
| Scene | Declarative animation timeline replacing a video |
| Scene brief | Our-words summary of a reference video, input to scene authoring |
| Pre-listen | App plays the passage before the student |
| Star gate | Node needing N stars to pass |
