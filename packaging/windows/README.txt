Easy Piano for Windows (x64)

ZIP bundle
1. Extract this ZIP to a folder.
2. Run easy_piano.exe.

Requirements
- Windows 10 or later, 64-bit.
- Microsoft Visual C++ v14 Redistributable (x64): https://aka.ms/vc14/vc_redist.x64.exe
- Speakers or headphones for piano audio.

The portable single-file executable embeds the Flutter bundle using Enigma Virtual Box. It does not install an updater or create a Start menu shortcut. The executable is unsigned; Windows SmartScreen or antivirus software may warn about it. If blocked, use the ZIP bundle instead.
